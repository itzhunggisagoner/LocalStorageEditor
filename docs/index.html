Edit safely

JSON, tidied

Install it in a minute

  1. Download the repo from GitHub and unzip it.
  2. Open chrome://extensions and switch on Developer mode.
  3. Choose Load unpacked and pick the folder that holds manifest.json.
  4. Pin the extension, open any site and click its icon.
